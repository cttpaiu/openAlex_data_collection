Commands Reference

All 10 commands — inputs, outputs, flags, and examples.

ℹ️ Running commands All commands are run via uv run openalex <command>. Every command reads config/collection.yml by default. Override with --config path/to/other.yml.
SETUP

openalex init

Create config template files to get started. Safe to run multiple times — existing files are not overwritten unless --force is passed.

Flags: --force — overwrite existing files
uv run openalex init
uv run openalex init --force   # overwrite existing files

Creates:

  • config/collection.yml — main config with API key placeholder
  • config/keywords.txt — example Boolean query
  • config/topics.txt — empty template with format instructions
  • data/raw/ and data/db/ directories
VALIDATE

openalex validate

Check keywords.txt and topics.txt before running any collection command. Runs 6 keyword syntax rules and optionally verifies each topic ID against the OpenAlex API.

Flags: --no-api — skip API check (offline, instant)
uv run openalex validate            # full check (requires API key)
uv run openalex validate --no-api   # syntax + format only

Exits with code 1 if any check fails. Safe to use in CI pipelines.

EXPLORE

openalex search

Count papers matching the keyword query only (no topic filter). Fires a single API request — very fast.

Flags: --dry-run — validate keywords, skip API call
uv run openalex search
uv run openalex search --dry-run

API call: GET /works?filter=title_and_abstract.search:{keywords},...&per_page=1

EXPLORE

openalex get-topics

List all research topics that appear in keyword search results, sorted by paper count. Uses the OpenAlex group_by API — no full result set download required.

Flags: --details — show paper count per topic  |  --csv — save to CSV file  |  --filter-topics — only show topics already in topics.txt 
uv run openalex get-topics                   # top 20 in terminal
uv run openalex get-topics --details         # all topics with counts
uv run openalex get-topics --details --csv   # save all to CSV (prompts filename)
uv run openalex get-topics --filter-topics   # only show your selected topics

Output CSV columns: topic_id, display_name, paper_count, percentage

💡 Typical workflow Run --details --csv, open the CSV, sort by paper_count, copy the relevant topic IDs into topics.txt.
EXPLORE

openalex search-filtered

Count papers matching both keywords AND topics filter. Validates all topic ID formats before calling the API. Requires topics.txt to have at least one valid ID.

Flags: --dry-run — validate only, skip API call
uv run openalex search-filtered
VALIDATE

openalex sample

Take a truly random sample of papers using reservoir sampling. Every paper in the result set has an equal chance of being selected, regardless of its page position. Use this to manually review whether your query returns relevant papers.

Flags: --size N (required) — number of papers to sample  |  --no-topics — keyword filter only 
uv run openalex sample --size 385            # recommended for ±5% confidence
uv run openalex sample --size 50             # quick sanity check
uv run openalex sample --size 100 --no-topics

Shows active filters, asks for confirmation, streams results, displays a table, and optionally saves to CSV.

Sample CSV columns: id, doi, title, publication_year, type, topic_id, topic_name, abstract_text, cited_by_count, fwci, institutions_count, countries_count

COLLECT

openalex download

Download all matching papers to a JSONL file. Uses 10 async concurrent streams with cursor-based pagination. Pre-flight check shows estimated total and disk space needed before asking for confirmation.

Flags: --output FILE — output filename (prompts if not given)  |  --no-topics — keyword filter only 
uv run openalex download
uv run openalex download --output quantum_2024.jsonl
uv run openalex download --no-topics --output keywords_only.jsonl

Output: JSONL file in data/raw/ — one JSON object per line, ~820 MB for 96k papers.

⚠️ Interruptions overwrite the file If the download is interrupted, re-running will start a fresh JSONL file. Resume support is planned for a future version.
COLLECT

openalex convert-to-db

Convert a JSONL file into a normalised DuckDB database with 5 tables. Handles deduplication, abstract reconstruction from inverted index, and auto-creates missing country records.

Flags: --input FILE — JSONL path (prompts if not given)  |  --output FILE — DB filename  |  --db-dir DIR — output directory 
uv run openalex convert-to-db
uv run openalex convert-to-db --input data/raw/quantum.jsonl --output papers.duckdb

5-table schema: papers, authors, institutions, countries, contributions

COLLECT

openalex check-db

Run completeness checks on a DuckDB database and display a health report. Display only — no files are written or modified.

Flags: --db FILE — path to database (prompts if not given)
uv run openalex check-db
uv run openalex check-db --db data/db/quantum_papers.duckdb

Checks: total papers, year range, authors/institutions/countries, papers with abstracts, papers with country info, Tier 1/2/3 classification, top 5 topics.
