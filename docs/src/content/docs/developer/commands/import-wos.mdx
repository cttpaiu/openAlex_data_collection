## File

`openalex/commands/import_wos.py`

## Per-file pipeline

```
data/QSM/<Country>.xlsx
            │
            ▼
country_code_for_file(filename) ─► ISO-3166 alpha-2  (HK normalised to CN)
            │
            ▼
build_doi_index + build_title_index    (per-run, in-memory)
            │
            ▼
for each WosRecord:
   _match_wos_to_paper(rec, doi_index, title_index, threshold, use_fuzzy)
      DOI hit → method='doi'
      exact normalised-title hit → method='title_exact'
      else fuzzy: token_sort_ratio ≥ threshold + year diff ≤ 2 + length ratio ≥ 0.6
   matched: _update_existing_paper(con, paper_id, rec)
   unmatched: _insert_new_paper(con, rec)   (id = "WOS_<accession>")
   _insert_wos_contribution(con, paper_id, country_code)
            │
            ▼
con.commit()  (per file)
```

## Schema migration

`_ensure_wos_schema(con)` issues:

```sql
ALTER TABLE papers ADD COLUMN IF NOT EXISTS from_wos BOOLEAN DEFAULT FALSE;
ALTER TABLE papers ADD COLUMN IF NOT EXISTS wos_accession_number VARCHAR;
ALTER TABLE contributions ADD COLUMN IF NOT EXISTS source VARCHAR DEFAULT 'openalex';
UPDATE contributions SET source = 'openalex' WHERE source IS NULL;
```

Safe to call repeatedly.

## Fuzzy matching guards

Three layered guards keep the fuzzy match precise:

1. **Scorer:** `fuzz.token_sort_ratio` — length-aware Levenshtein after sort. The original `token_set_ratio` collapsed every long-WoS-title onto OpenAlex's one-word "Magnetoencephalography" (token-set returns 100% when one set is a subset of the other).
2. **Year guard:** If both WoS and OpenAlex publication years are known and differ by more than 2, reject the match. Catches "He atoms in strong external fields" vs "Li atom in strong external fields".
3. **Length ratio:** `min(len_q, len_m) / max(len_q, len_m) ≥ 0.6` — second-line defence against length mismatches the scorer alone might miss.

## Idempotency

- Matched papers: `_update_existing_paper` uses `COALESCE` on `wos_accession_number` so a second run doesn't overwrite an earlier accession. `from_wos` flag stays TRUE.
- New papers: `INSERT … ON CONFLICT DO NOTHING` keyed on the deterministic `WOS_<accession>` id.
- WoS contributions: `_insert_wos_contribution` checks `EXISTS … WHERE source='wos'` before inserting.
- During one run, newly inserted WoS-only papers are also added to the in-memory DOI/title indexes so later rows can deduplicate against them.

Re-running `import-wos` on the same DB is a no-op for already-imported files.

## Dependencies

## Gotchas

- The fuzzy threshold default (0.95) was tuned manually. Lower it for higher recall at the cost of false positives — sample-audit before applying.
- WoS contributions have `author_id = NULL, institution_id = NULL`. Joins that expect non-NULL author / institution must filter `WHERE source = 'openalex'`.
- 36 country files were spot-checked. Files not in `COUNTRY_FILE_TO_CODE` (e.g. a new country export) are skipped with a `[yellow]⚠ skipping[/yellow]` warning.
- `--dry-run` still counts projected WoS contribution rows and new papers, but it does not mutate the database.
