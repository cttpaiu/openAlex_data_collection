## File

`openalex/commands/database.py`

## Class layout

- `OpenAlexLoader(db_path, jsonl_path)` — constructor opens the DuckDB connection, creates schema, initialises the `seq_contrib` sequence (starts at `MAX(row_id)+1` for resumes), loads caches.
- `load_existing_caches()` — pulls existing `authors.id` + `institutions.id` into in-memory sets so reruns skip duplicates without a SELECT per row.
- `process_record(record)` — main per-paper handler. Skips on PK conflict, otherwise inserts paper + authorship rows.
- `_load_country_cache()` — loads existing `countries.country_code` values so `_ensure_country()` can avoid repeated inserts.
- `_ensure_country(code)` — HK→CN remap + insert into `countries` if new.
- `_insert_institution(data)` — caches by id; idempotent.
- `_insert_author(data)` — same.
- `_reconstruct_abstract(inv)` — local OpenAlex inverted-index reconstruction; returns `None` on missing/malformed input.
- `_first_nonempty_affiliation(raw_affs)` — fallback for institution-less authorships.

## Click flow

When `--input` is omitted, the command prompts for a JSONL path with `data/raw/openalex.jsonl` as the default. When `--output` is omitted, it prompts for a database filename with `quantum_papers.duckdb` as the default. `--db-dir` overrides `cfg.db_dir`; otherwise the output directory comes from config and is created if needed.

## Schema

`_create_schema()` issues `CREATE TABLE IF NOT EXISTS` for all five tables + an `ALTER TABLE … ADD COLUMN IF NOT EXISTS is_synthetic` migration on `institutions`. See **[DuckDB schema](../../schema/)** for column-level detail.

## Idempotency

- `papers` is the dedup root. `SELECT 1 FROM papers WHERE id = ?` skips re-inserts.
- `contributions` uses `nextval('seq_contrib')` for `row_id`. Re-running over the same JSONL won't append duplicate rows because the paper-level skip short-circuits.
- `authors` and `institutions` use the in-memory cache → `ON CONFLICT DO NOTHING`.
- `_ensure_country` checks cache → INSERT … ON CONFLICT DO NOTHING.

## HK → CN remap

Applied at load time via `normalize_country_code` inside `_insert_institution`, `_ensure_country`, and the authorship country fallback. New databases come out of `convert-to-db` already remapped.

## Authorship handling

- Authorships with institutions produce one contribution per listed institution. Raw affiliation strings are paired by institution index when available.
- Authorships without institutions still produce one contribution row with `institution_id = NULL`, the first author-level country when present, and the first non-empty raw affiliation string. This keeps rows eligible for later CrossRef/PDF/LLM enrichment.
- `is_international` is computed from `countries_distinct_count > 1`; missing or zero counts become `False`.

## Dependencies

- in-repo: `openalex/imputation.py::normalize_country_code`.
- 3rd-party: `duckdb`, `rich`.

## Gotchas

- Out-of-disk mid-run can corrupt the DB. Pre-check disk before starting on a large corpus.
- The `seq_contrib` sequence isn't shared across DuckDB files. Each fresh DB starts at 1.
