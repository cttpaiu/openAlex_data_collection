## Purpose

Thin Click group that imports every command function from `openalex/commands/*.py` and registers them. Also defines the `impute` subgroup that hosts `crossref` / `llm` / `pdf`.

The module docstring on the `cli()` function is the **canonical workflow order** — keep it in sync when adding commands.

## Public API

| Symbol | Kind | Notes |
|---|---|---|
| `cli` | `click.Group` | Top-level entry; registered as `openalex` via `[project.scripts]` in `pyproject.toml` |
| `impute_group` | `click.Group` | Subgroup; hosts `crossref`, `llm`, `pdf` |

## Registration pattern

```python
cli.add_command(extract_keywords_command)
cli.add_command(build_categorized_query_command)
cli.add_command(compare_dois_command)
cli.add_command(wos_import_impute_command)

from openalex.commands.impute_affiliation import impute_affiliation_command
...
impute_group.add_command(enrich_crossref_command)   # canonical name "crossref"
impute_group.add_command(impute_affiliation_command) # canonical name "llm"
impute_group.add_command(impute_pdf_command)        # canonical name "pdf"
cli.add_command(impute_group)

# Deprecation aliases — old top-level names still work for one release:
cli.add_command(enrich_crossref_command, name="enrich-crossref")
cli.add_command(impute_affiliation_command, name="impute-affiliation")
```

The command decorators on the underlying command functions control the canonical CLI names. The subgroup registrations rely on `@click.command("crossref")`, `@click.command("llm")`, and `@click.command("pdf")`.

`click` is pinned in `pyproject.toml` because the old top-level aliases use `add_command(..., name="...")`.

## In-repo dependencies

Imports every command function from `openalex.commands.*`. No business logic.

## 3rd-party
