---
title: check-anchor
description: "Verify that every must-find paper in anchor.txt appears in the current filter."
---

```sh
uv run openalex check-anchor [--no-topics]
```

## What it does

For each line in `config/anchor.txt` (DOI or full title), checks whether it appears in the current keyword + topic filter. Reports counts for checked, found, missing, and invalid entries.

Use `--no-topics` to check anchors against the keyword-only filter instead.

## Options

| Flag | Default | Description |
|---|---|---|
| `--config` | `config/collection.yml` | Config file path |
| `--no-topics` | off | Check anchors against keywords only |

## Example

```sh
uv run openalex check-anchor
```

```text
Anchor Coverage — Filtered search (keywords + topics)
  Anchors checked    12
  Found              11
  Missing             1

✗ Missing anchors:
  • [title] Quantum supremacy using a programmable superconducting processor
```

## Gotchas

- Title matches are exact (whitespace + case normalised). If the anchor title has trailing punctuation or unicode quirks, it may fail.
- Malformed DOI-looking entries are reported as invalid and cause a non-zero exit.
- A `MISSING` anchor either:
  - is not on OpenAlex at all,
  - has a different DOI / title than what you pasted,
  - falls outside the date range, doc-type filter, or topic filter.
