## Requirements

| | Version |
|---|---|
| Python | ≥ 3.13 |
| [uv](https://docs.astral.sh/uv/) | latest |
| OpenAlex API key | free — [request one](https://openalex.org/account) |
| Disk | ≥ 2 GB free for the JSONL + DuckDB |
| Optional: Ollama | for local LLM imputation |

## Clone + install

```sh
git clone https://github.com/Darunesh1/openAlex_data_collection.git
cd openAlex_data_collection
uv sync   # creates .venv, installs deps from uv.lock
```

`uv sync` reads `pyproject.toml` + `uv.lock` and installs everything (incl. the `dev` group with `pytest`). No system Python pollution.

## Verify

```sh
uv run openalex --help
```

You should see the top-level command list with `init`, `validate`, `search`, …, `impute`, `import-wos`, `export-format`.

## Optional: Ollama for local LLM imputation

`openalex impute llm` and `openalex impute pdf` default to a local Ollama model.

```sh
brew install ollama
ollama serve   # in one terminal
ollama pull sorc/qwen3.5-instruct:2b   # default model
```

Keep `ollama serve` running for the lifetime of any `impute` invocation. Cloud Groq is opt-in via `--llm-provider groq`.
