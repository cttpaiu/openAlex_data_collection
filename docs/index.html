OpenAlex CLI

A command-line pipeline for collecting, validating, and storing quantum computing publications from the OpenAlex API.

Get Started → View Commands

What is this?

The OpenAlex CLI automates a multi-step data collection pipeline that was previously spread across four Jupyter notebooks and manual copy-pasting. It wraps every stage — from query validation to database loading — into a single tool you run from the terminal.

The target dataset is quantum computing research papers (2003–2024) collected from the OpenAlex open scholarly database — roughly ~96,000 papers across 89 research topic IDs.

Features

🔍

Query validation

Six syntax rules catch malformed Boolean queries before any API call is made.

⚡

Async downloads

10 concurrent streams with cursor-based pagination handle 96k+ papers efficiently.

🎲

Reservoir sampling

Truly random samples from large result sets to validate query quality before full download.

🗄️

Normalised DuckDB

5-table relational schema: papers, authors, institutions, countries, contributions.

📊

Health reports

Tier 1/2/3 completeness classification on every database after loading.

🎨

Rich terminal UI

Coloured panels, progress bars, and tables — no plain text walls.

The 10-Command Pipeline

openalex init                        # 1. create config templates
openalex validate                    # 2. check keywords + topics files
openalex search                      # 3. how many papers match keywords?
openalex get-topics                  # 4. what topics appear?
openalex get-topics --details --csv  # 5. count per topic → save CSV
openalex search-filtered             # 6. keyword + topic filter count
openalex sample --size 385           # 7. random validation sample
openalex download                    # 8. download all → JSONL (~820 MB)
openalex convert-to-db               # 9. JSONL → DuckDB
openalex check-db                    # 10. completeness health report

Quick Start

terminal 
# 1. Clone and install
git clone https://github.com/Darunesh1/openAlex_data_collection.git
cd openAlex_data_collection
uv sync

# 2. Create config templates
uv run openalex init

# 3. Add your API key to config/collection.yml
# 4. Add topic IDs to config/topics.txt (one per line)

# 5. Validate everything before hitting the API
uv run openalex validate --no-api    # fast, offline
uv run openalex validate             # + API existence check

# 6. Run the pipeline
uv run openalex search
uv run openalex download
uv run openalex convert-to-db
uv run openalex check-db
💡 Tip Run openalex validate every time you edit keywords.txt or topics.txt. It catches syntax errors before they cause a failed 820 MB download.
