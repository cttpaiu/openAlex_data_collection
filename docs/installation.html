Installation

Get the OpenAlex CLI running in under 5 minutes.

Prerequisites

RequirementVersionNotes
Python≥ 3.13Check with python --version
uvlatestPackage manager — install guide
OpenAlex API key—Free — request here
Disk space≥ 2 GB~820 MB for JSONL + ~200 MB for DuckDB
ℹ️ Why uv? This project uses uv exclusively for dependency management. Never use bare pip install — it will install into the wrong environment.

Step 1 — Clone the repository

git clone https://github.com/Darunesh1/openAlex_data_collection.git
cd openAlex_data_collection

Step 2 — Install dependencies

uv sync

This installs all dependencies and registers the openalex command into the project's virtual environment. Takes about 30 seconds on first run.

Step 3 — Verify installation

uv run openalex --help

You should see the full command list. If you get command not found, make sure you're inside the project directory and ran uv sync.

Step 4 — Create config files

uv run openalex init

This creates three files:

  • config/collection.yml — main config (API key, dates, batch sizes)
  • config/keywords.txt — your Boolean search query
  • config/topics.txt — OpenAlex topic IDs, one per line

It also creates data/raw/ and data/db/ output directories.

Step 5 — Add your API key

Open config/collection.yml and replace the placeholder:

config/collection.yml 
api:
  key: "YOUR_API_KEY_HERE"    # ← replace this
  email: "your@email.com"     # ← and this
⚠️ Keep your API key private Never commit config/collection.yml with a real API key to a public repository. Add it to .gitignore or use an environment variable.

Step 6 — Add topic IDs

Edit config/topics.txt — one topic ID per line. Lines starting with # are ignored.

config/topics.txt 
# Quantum computing core topics
T10020
T10682
T10382
T10657
T10425

Don't know which topic IDs to use? Run openalex get-topics after setting up keywords to discover them automatically.

Step 7 — Validate before collecting

# Offline syntax check only
uv run openalex validate --no-api

# Full check including API existence verification
uv run openalex validate

Both files must pass validation before any collection command will work reliably. See Validation Rules for details.

Directory structure after init

openAlex_data_collection/
├── config/
│   ├── collection.yml     ← main config
│   ├── keywords.txt       ← Boolean query
│   └── topics.txt         ← topic IDs
├── data/
│   ├── raw/               ← JSONL downloads land here
│   └── db/                ← DuckDB files land here
├── openalex/              ← Python package
└── pyproject.toml
✅ Ready! Once validation passes, follow the End-to-End Workflow to collect your dataset.
